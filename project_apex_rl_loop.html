Project Mission
Core Objective

An off-policy SAC reinforcement learning agent manages a long-only equity portfolio drawn from the Nasdaq-100 universe, rebalancing weekly. The agent optimizes for risk-adjusted excess return over the QQQ ETF benchmark.

J(π) = Eπ[ Σt γt · rt ]
J(π)Total expected cumulative reward — what the agent maximizes πThe policy — the neural network that picks portfolio weights each week EπExpected value over many episodes run under policy π ΣtSum across all future weekly time steps γtDiscount factor (γ=0.975) — rewards far in the future count for less rtWeekly reward: excess return vs QQQ minus risk, cost & violation penalties
Hard Portfolio Constraints
Long-only: wexec,i ≥ 0 for all i
Fully invested: Σ wexec,i = 1.0 always
Per-name cap: wexec,i ≤ 20%
Sector cap: Σsector wexec,i ≤ 50%
Non-member exposure = 0 (mask enforced)

Enforced by a differentiable ConstraintProjector at every step.

Training & Evaluation Design
Folds
8 rolling 6-year windowsEach fold trains on a fixed 6-year window (5yr for Fold 1) that slides forward by 2 years per step — F1: 2005–2009, F2: 2006–2011, …, F8: 2018–2023. The model is retrained from scratch each fold, testing generalization across distinct market eras.
Embargo
4 weeksHard gap between train end and test start. Prevents n-step returns (n=4) from spanning the fold boundary and leaking future returns into training.
Primary OOS Metrics
Excess CAGR, Sortino, Max DrawdownComputed on concatenated OOS weeks across all folds. Block bootstrap CIs on cross-fold performance.
